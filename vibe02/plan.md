# 사과 숫자 퍼즐 게임 앱 기획서

## 1. 프로젝트 목표

HTML, CSS, JavaScript만 사용해 누구나 파일을 열어 바로 실행할 수 있는 간단한 숫자 퍼즐 웹게임을 제작한다. 사용자는 8행 6열의 사과 격자에서 인접한 사과를 드래그 또는 터치로 연결하고, 선택한 숫자의 합이 10이 되면 사과를 제거해 점수를 얻는다.

## 2. 기술 및 실행 환경

- HTML5, CSS3, Vanilla JavaScript(ES6+)만 사용한다.
- React, Vue, Bootstrap, Tailwind CSS 등 외부 프레임워크와 라이브러리는 사용하지 않는다.
- 별도의 빌드 과정이나 서버 없이 `index.html`을 브라우저에서 직접 열어 실행할 수 있어야 한다.
- 다음 파일로 분리해 구성한다.
	- `index.html`: 게임 화면 구조
	- `style.css`: 화면 디자인과 반응형 스타일
	- `script.js`: 게임 상태, 입력, 판정, 보드 갱신 로직

## 3. 게임 기본 규칙

- 게임 보드는 8행 6열, 총 48칸으로 구성한다.
- 게임 시작 시 모든 칸에 사과 하나씩 배치한다.
- 각 사과에는 1부터 9 사이의 숫자를 무작위로 표시한다.
- 사과는 실제 이미지 파일 없이 CSS로 사과 모양을 표현하거나, 접근성을 고려한 이모지와 숫자를 조합해 표현한다.
- 사용자는 상하좌우 또는 대각선으로 연결된 인접 사과를 순서대로 선택할 수 있다.
- 선택한 사과의 숫자 합이 정확히 10이면 성공 처리한다.
- 합이 10이 된 선택 경로에 포함된 사과를 모두 제거한다.
- 제거한 사과 1개마다 2점을 추가한다.
	- 점수 계산식: `획득 점수 = 제거한 사과 수 × 2`
- 선택한 숫자의 합이 10보다 작으면 추가 인접 사과를 계속 선택할 수 있다.
- 선택한 숫자의 합이 10보다 크면 해당 선택을 취소하고 원래 보드 상태로 되돌린다.
- 합이 10이 아닌 상태에서 손을 떼거나 드래그를 종료하면 선택을 취소한다.
- 같은 드래그 경로에서 이미 선택한 사과를 다시 선택할 수 없다.

## 4. 보드 갱신 규칙

성공적으로 사과가 제거되면 다음 순서로 보드를 갱신한다.

1. 선택된 사과를 제거하고 해당 칸을 빈 칸으로 만든다.
2. 각 열에서 빈 칸 위에 있는 사과가 아래로 떨어지도록 정렬한다.
3. 사과가 내려간 뒤 열의 위쪽에 생긴 빈 칸을 새로운 사과로 채운다.
4. 새 사과에도 1~9 사이의 숫자를 랜덤하게 부여한다.
5. 갱신이 끝나면 사용자가 다시 선택할 수 있도록 선택 상태를 초기화한다.

사과가 떨어지고 새로 채워지는 동작에는 짧은 CSS 애니메이션을 적용해 변화가 자연스럽게 보이도록 한다. 애니메이션 중에는 중복 입력을 막는다.

## 5. 사용자 입력 방식

- 마우스 사용자는 사과를 누른 뒤 인접한 사과로 드래그해 경로를 만든다.
- 터치 사용자는 손가락으로 사과를 누른 뒤 인접한 사과로 이동해 경로를 만든다.
- `pointerdown`, `pointerenter`, `pointerup` 이벤트를 중심으로 구현해 마우스와 터치 입력 로직을 통합한다.
- 선택 중인 사과는 색상, 테두리, 확대 효과로 명확하게 표시한다.
- 현재 선택 경로와 선택한 숫자의 합을 화면에 표시한다.
- 선택 중에는 선택된 숫자 합계가 실시간으로 갱신되어야 한다.
- 보드 밖에서 입력을 종료해도 게임 상태가 멈추거나 고장 나지 않아야 한다.

## 6. 화면 구성

### 상단 영역

- 게임 제목: `Apple Sum 10`
- 짧은 안내 문구: `인접한 사과를 연결해 합을 10으로 만들어보세요!`
- 현재 점수 표시
- 현재 선택 숫자 합계 표시

### 게임 영역

- 중앙에 8행 6열 사과 격자를 배치한다.
- 각 사과는 숫자를 쉽게 읽을 수 있도록 충분한 크기와 대비를 가져야 한다.
- 데스크톱에서는 보드가 화면 중앙에 안정적으로 배치되어야 한다.
- 모바일에서는 화면 너비에 맞춰 보드가 축소되되 6열 구조가 유지되어야 한다.

### 하단 영역

- `다시 시작` 버튼을 제공한다.
- 다시 시작하면 점수를 0으로 초기화하고 48개의 새 사과를 생성한다.
- 게임 방법을 짧게 보여주는 안내 영역을 제공한다.

## 7. 디자인 방향

- 밝고 친근한 분위기의 캐주얼 퍼즐 게임으로 디자인한다.
- 사과를 쉽게 구분할 수 있도록 빨강, 초록, 노랑 계열을 활용하되 숫자 가독성을 우선한다.
- 게임판은 둥근 모서리와 부드러운 그림자를 사용한다.
- 선택 상태, 성공 상태, 실패 상태를 색상과 모션으로 구분한다.
- 버튼에는 hover와 active 상태를 적용한다.
- 작은 화면에서도 텍스트가 겹치거나 버튼이 화면 밖으로 밀리지 않도록 반응형으로 구성한다.
- 애니메이션을 줄여야 하는 사용자를 위해 `prefers-reduced-motion` 설정을 존중한다.

## 8. 게임 상태 및 주요 함수 예시

다음과 같은 상태와 함수 구조를 권장한다.

- 상태
	- `board`: 8행 6열 숫자 배열
	- `score`: 현재 점수
	- `selectedCells`: 현재 선택된 셀 목록
	- `selectedSum`: 현재 선택 숫자 합계
	- `isDragging`: 입력 진행 여부
	- `isAnimating`: 보드 갱신 애니메이션 진행 여부

- 함수
	- `createBoard()`: 초기 보드 생성
	- `createApple()`: 1~9 랜덤 숫자 사과 생성
	- `renderBoard()`: 현재 상태를 화면에 렌더링
	- `isAdjacent(firstCell, secondCell)`: 두 칸의 인접 여부 확인
	- `selectCell(cell)`: 선택 경로에 셀 추가
	- `clearSelection()`: 현재 선택 초기화
	- `completeSelection()`: 합계가 10인지 판정
	- `removeSelectedCells()`: 선택 사과 제거 및 점수 반영
	- `collapseColumns()`: 열별 사과 낙하 처리
	- `fillEmptyCells()`: 빈 칸을 새 사과로 채우기
	- `resetGame()`: 게임 전체 초기화

## 9. 예외 및 품질 조건

- 합이 10인 경우에만 사과를 제거한다.
- 합이 10보다 커지는 순간 더 이상 사과를 선택하지 못하게 하고 현재 선택을 취소한다.
- 인접하지 않은 사과는 선택할 수 없다.
- 동일한 사과를 한 경로에서 중복 선택할 수 없다.
- 점수는 사과가 실제로 제거된 경우에만 증가한다.
- 새로 생성되는 사과는 항상 1~9 범위의 숫자를 가진다.
- 숫자와 상태 변화는 스크린 리더가 이해할 수 있도록 적절한 `aria-label` 또는 상태 안내를 제공한다.
- 버튼과 사과 칸은 키보드 포커스를 확인할 수 있어야 한다.
- 콘솔 오류 없이 최신 Chrome, Edge, Firefox에서 실행되어야 한다.

- [ ] 8행 6열, 총 48개의 사과가 표시된다.
- [ ] 모든 사과의 숫자가 1~9 사이에서 랜덤 생성된다.
- [ ] 마우스 드래그로 인접 사과를 선택할 수 있다.
- [ ] 터치 드래그로 인접 사과를 선택할 수 있다.
- [ ] 선택 숫자 합이 실시간으로 표시된다.
- [ ] 합이 10이면 선택된 사과가 제거되고 사과 수에 따라 2점씩 추가된다.
- [ ] 제거 후 사과가 아래로 내려오고 위쪽 빈 칸이 새 사과로 채워진다.
- [ ] 합이 10보다 크거나 입력을 종료하면 선택이 취소된다.
- [ ] 다시 시작 버튼이 점수와 보드를 초기화한다.
- [ ] 데스크톱과 모바일 화면에서 레이아웃이 깨지지 않는다.
