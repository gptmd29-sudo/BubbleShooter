# 역할(Role)
당신은 10년 경력의 시니어 프런트엔드 개발자이자 UI/UX 디자이너입니다. 또한 최근 트렌드의 포트폴리오 및 랜딩 페이지를 잘 만드는 전문가입니다.

# 목표(Goal)
vibe01 폴더에 있는 profile.txt 파일의 내용을 분석해서 개인 포트폴리오(자기소개서) 랜딩 페이지를 제작하는 것이 목표입니다.

# 참고자료(Context)
- vibe01/profile.txt : 자기소개 내용
- vibe01/images/profile.png : 프로필 사진

# 지침(Instruction) 또는 요구사항(Requirements)

## 1. 기술 요구사항
- HTML5
- CSS3
- JavaScript(ES6+)

위 기술만 사용해서 구성해줘. Bootsstrap이나 Tailwind, React 등의 기술은 사용하지 말아줘.

파일은 아래처럼 분리해서 구성합니다.
- index.html
- style.css
- script.js

## 2. UI/UX 요구사항
- 최근 트렌드의 미니멀한 포트폴리오 사이트를 만들어주세요.
- 반응형 웹으로 구성해주세요.
- 주요 키워드
    * 깔끔한 레이아웃
    * 카드형 디자인
    * 둥근 모서리
    * 부드러운 그림자
    * 은은한 그라데이션
    * 읽기 쉬운 타이포그래피
- 색상은 아래 색상을 중심으로 사용합니다.
   * #3A86FF
   * #BDB2FF
   * #FFD6E0
   * #FFF4F4
   * 화이트
   * 그레이

- Header 구성
    로고/메뉴(Home/About/Contact)
    상단에 고정(Fixed Header)
- Hero Section
    profile.png 를 원형으로 표시
    자기소개
    한 줄 소개
    CTA 버튼
- About/Contact 내용은 profile.txt를 분석해서 적절한 내용으로 구성해줘.
- Footer
    저작권 문구

- ux 요구사항
    * 메뉴 클릭 시 해당 영역으로 이동
    * css의 부드러운 스크롤 기능
    * 현재 보고 있는 메뉴에 Active 표시
    * 버튼/카드 hover 효과
    * Fade In 애니메이션
    * 모바일에서도 보기 좋은 반응형
